## Descrição do Projeto

Este projeto consiste no desenvolvimento de uma plataforma web completa para a **ONG Esperança Solidária**, uma organização fictícia do terceiro setor. A plataforma foi desenvolvida aplicando os fundamentos de HTML5 estudados na Unidade 1, com foco em estrutura semântica, formulários interativos e acessibilidade.

### Objetivos Alcançados

A entrega contempla todos os requisitos técnicos obrigatórios:

1. **Estrutura HTML5 Semântica Completa**
   - 3 páginas HTML totalmente estruturadas
   - Uso adequado de elementos semânticos (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<figure>`, `<blockquote>`, `<address>`)
   - Hierarquia de títulos lógica e consistente
   - Meta tags para SEO (description, keywords, viewport)

2. **Páginas Implementadas**
   - **index.html** - Página inicial com apresentação da organização, missão, visão, valores, áreas de atuação e informações de contato completas
   - **projetos.html** - Página de projetos sociais, oportunidades de voluntariado e sistema de doações
   - **cadastro.html** - Formulário completo e interativo de cadastro de voluntários

3. **Formulário Complexo e Interativo (cadastro.html)**
   - Implementação de todos os 9 campos obrigatórios:
     - Nome Completo, E-mail, CPF, Telefone, Data de Nascimento
     - Endereço, CEP, Cidade, Estado
   - Validação nativa HTML5 com atributos `required`, `pattern`, `minlength`, `maxlength`
   - Máscaras de input para CPF (000.000.000-00), Telefone ((00) 00000-0000) e CEP (00000-000)
   - Agrupamento lógico com `<fieldset>` e `<legend>`
   - Múltiplos tipos de input HTML5: text, email, tel, date, checkbox, radio, select, textarea
   - Atributos de acessibilidade (`aria-required`)

4. **Recursos Adicionais Implementados**
   - 15 imagens otimizadas organizadas no diretório `img/`
   - Estrutura de pastas profissional (css/, js/, img/, assets/, docs/)
   - Arquivo `.gitignore` configurado
   - README.md com documentação completa do projeto
   - Uso de `<figure>` e `<figcaption>` para galeria de imagens
   - Implementação de `<blockquote>` e `<cite>` para depoimentos
   - Links externos com `target="_blank"` e `rel="noopener"`
   - Navegação consistente em todas as páginas
