## 🎓 Conceitos Aplicados

### CSS Grid
- Grid template columns/rows
- Gap e grid-gap
- Auto-fit e auto-fill
- Grid de 12 colunas

### Flexbox
- Justify-content e align-items
- Flex-direction e flex-wrap
- Flex-grow, flex-shrink, flex-basis
- Alinhamento de elementos

### CSS Variables
- Custom properties (--var)
- Reutilização de valores
- Design system escalável
- Tematização facilitada

### Media Queries
- Breakpoints estratégicos
- Mobile-first approach
- Responsive images
- Print styles

### Pseudo-classes
- :hover, :focus, :active
- :checked (para menu hambúrguer)
- :nth-child, :first-child, :last-child
- :valid, :invalid

### Transitions & Transforms
- transition-property, duration, timing
- transform: translateX, translateY, rotate, scale
- Animações suaves
- Estados interativos
